# Changelog (Beta)

All notable changes to the beta channel are documented here.
Format follows https://keepachangelog.com/en/1.1.0/

## [1.8.6b] - 2026-07-16

### Added
- Sleep timer, overhauled (Settings > Playback > Sleep timer):
  - Fades the volume out over the last few seconds instead of an abrupt hard stop (configurable, off = old hard-pause behavior)
  - "End of chapter" option — pauses when the current chapter ends instead of a fixed duration
  - Shake to extend — shake the phone near the end of the timer (or right after it pauses) to keep listening
  - Optional nightly auto-start — automatically arms the timer when you start playing within a time window you set
  - The timer now lives in the playback service instead of the app process, so it reliably fires even if the app is swiped away while it's counting down

## [1.8.5b] - 2026-07-16

### Fixed
- Backup: importing a backup crashed with "MediaController method is called from a wrong thread" — restore now stops playback on the correct thread before applying the restore

## [1.8.4b] - 2026-07-16

### Added
- Backup & restore: Settings → Backup & restore can now export your progress, bookmarks, listening history, audio presets, and series to a file, and restore from one. Restore matches books by folder/title, not by an internal id, so it survives a reinstall or rescan. Optional daily auto-backup to a folder you choose (keeps the last 5), plus a "Share backup" action. Your Gemini AI key is only included if you explicitly check the box, and shared/auto backups never include it.

### Fixed
- Playback: a file with a corrupt/malformed start no longer refuses to play — the app now shows a message and automatically retries further into the file (escalating up to 30s) to find clean audio, instead of failing outright
- Scanner: books whose filenames use "pt N" / "part N" for multi-part files (e.g. "... pt 1.mp3", "... pt 2.mp3") no longer get mis-split into separate one-file "books" — they now import correctly as a single multi-part book

## [1.8.3b] - 2026-07-08

### Added
- Listening and reading are now linked: play the audiobook after reading and it picks up from where you stopped reading (and vice versa) — whichever you did more recently wins
- "Listen from here", "Read from here", and chapter/TOC jumps in the reader now show up in a book's History, alongside the existing listening skips — and if a standalone ebook gets connected to its audiobook, their two histories merge into one instead of the ebook's being lost

### Fixed
- The mini player now shows the last-played book immediately on a cold app launch, instead of staying blank until you open the full player
- Cover art: a `cover.png` dropped into a book's own folder now takes priority over the auto-extracted embedded cover; covers set from the in-app search are also saved as `cover.png` so they're easy to find/replace
- Fixed the ebook reader sometimes forgetting your exact scroll position if you closed the book right after scrolling
- Paragraph-resolution sync alignment can now be exported/imported as a `mapping.json` file inside a book's folder — carried over automatically on a rescan, or on demand from the reader's overflow menu
- Folder picker: Cancel/Select buttons pushed further clear of the gesture bar on some devices

## [1.8.2b] - 2026-07-07

### Changed
- On-device sync alignment ("Improve sync") is significantly faster: it now locates each audio chapter/part's start in the book first, then only searches that part's own section of text instead of the whole book on every check. Snippet length also reduced from 25s to 15s

## [1.8.1b] - 2026-07-07

### Added
- Ebooks are now a top-level section of their own (Audio | Ebooks switch on the home screen) instead of a view inside the audio library
- Listen ↔ read sync now goes down to the paragraph: an optional, fully on-device speech-recognition pass (Settings → AI, or "Improve sync" in the reader) finds verified reference points through the chapter so "Read from here" / "Listen from here" land much closer to the exact spot, even with no internet connection

### Fixed
- Paragraph-resolution sync no longer trusts the (sometimes wrong) audio-chapter-to-epub-chapter mapping once it has verified reference points — audiobooks split into narration "Parts" rather than real chapters could otherwise throw the sync off

## [1.8.0b] - 2026-07-06

### Added
- Ebook reader: attach an EPUB to any audiobook (or drop standalone EPUBs in a separate ebook folder), then read or listen and always continue from the same spot — "Read from here" and "Listen from here" convert your position between the two automatically. Includes a new Ebooks tab in the library, chapter alignment (auto + manual), font size control, and a locked-down in-app reader with no network access
- Two full app themes in Settings → Theme, chosen on first launch: Material You (tonal, wallpaper or cover colors) and Immersive (blurred full-bleed cover behind everything, all text tinted to match)
- Audio presets are now full bundles (speed + volume boost + EQ); one preset can be set as the library-wide default so new and existing books get consistent audio unless individually tuned. Manage them from Settings → Audio presets
- Multi-select in the library: long-press any book, series, or author (mixed selections supported) to delete, add books to a series, or reach cover search/book options from one selection bar
- Home-screen widget: set a custom default cover shown when nothing is playing (Settings → Widget)
- Hold a skip button in the player to change its interval; swipe the mini player down to close the current book

### Fixed
- Mini player now reliably restores after a cold app launch
- Mini player no longer shows on the Settings screen
- Folder picker's Cancel/Select buttons were sometimes clipped by the gesture bar
- Tapping a book's play button in the library no longer opens the full player

## [1.6.9b] - 2026-07-02

### Fixed
- Changing a series' author (or narrator) now actually updates every book in the series — it shows in each book's options, the Authors view, and the player. The Authors view now groups by the effective author, so an author you change is reflected right away

### Changed
- Restructure files now asks which layout to use (Author / Series / Book, or Author - Series / Book) before it moves anything, and removes the now-empty leftover folders after the move
- A cover you set from an online search is now saved inside the book's own folder, so it stays with the audio and travels with a restructure move

## [1.6.8b] - 2026-07-02

### Added
- Restructure files on disk (Settings → Library): moves your audio-book folders to match the chosen Author / Series / Book layout, using each book's author and series — so series/author changes you make in the app can be reflected in the actual folders. Every move is copy → verify → delete-original, so nothing is lost; books already in place or without a real folder are skipped, and it shows how many will move before you confirm

## [1.6.7b] - 2026-07-02

### Added
- Series options: on a series screen tap the tune icon to set a default playback speed, volume boost, skip-silence, author, and narrator for the whole series. Every book inherits these unless it has its own setting — a book you've individually tuned keeps its own speed/boost/EQ
- A book with no author/narrator of its own now shows the series' author/narrator in the player

## [1.6.6b] - 2026-07-02

### Added
- The chapters list, while a series is playing, now shows **every book in the series** with its chapters (a header per book). Tap a chapter in the current book to seek; tap one in another book to jump straight to that book and continue the series from there

### Changed
- Switching a series book to "Show series cover" now recolors the **whole app theme** from the series cover too — not just the player backdrop

## [1.6.5b] - 2026-07-02

### Changed
- Series now play in the **exact same player as a single book** — no separate "group" player. A series plays one book at a time and automatically rolls into the next book when one ends, and the open player follows along. This means series get the full player: book options, listening history, chapters, bookmarks — everything a normal book has
- The book↔series cover toggle now lives in any series book's ⋮ menu ("Show series cover" / "Show book cover")

## [1.6.4b] - 2026-07-02

### Added
- Player cover toggle: while a series is playing, use the ⋮ menu to switch between the series cover and the current book's cover
- When a series rolls from one book into the next, the book you just finished is now marked Finished automatically, so in Books view it correctly shows as done and the series resumes at the next unfinished book

## [1.6.3b] - 2026-07-02

### Fixed
- Tapping a book on the series screen now plays the whole series starting from that book, so it continues into the following books instead of stopping when that one book ends

### Added
- Series screen is now a proper series manager: a "Play series" button, plus add books, remove books, reorder books (up/down), and rename the series
- Opening a series from the home Series view now opens this manager and can launch straight into the player

## [1.6.2b] - 2026-07-02

### Fixed
- Playing a series now continues across books: when one book finishes, the next book in the series starts automatically instead of stopping. Each book still keeps its own progress, so resuming a series picks up exactly where you left off
- The full player screen now shows the series (name, cover, and a chapter list grouped by book) when a series is playing

## [1.6.1b] - 2026-07-02

### Added
- Home library view modes: switch between Books, Series, and Authors with the pill switch above the status tabs
- Series view groups your books into series tiles — tap to open the series, or tap the play button to resume that series where you left off (it continues from the book you last had in progress)
- Authors view groups your books by author — tap to see all of that author's books
- Change a tile's cover per view: long-press a Series or Author tile to set its own cover from an online search. It changes only that tile — the member books keep their own covers

### Changed
- The old manual "join books" grouping is fully replaced by the Series system

## [1.6.0b] - 2026-07-02

### Fixed
- Update checker now finds new releases reliably. GitHub lists releases by tag-commit date, not version, so a release cut from an older tag could sort below older ones and be missed entirely — the app now picks the highest version number instead of trusting the list order, and scans more releases
- The folder picker's Select / Cancel buttons are no longer cut off behind the gesture navigation bar

### Added
- Choose how your library folders are read: Automatic, Author / Series / Book, or Author - Series / Book. Pick it on first launch or in Settings → Library → Library structure
- The app now detects when audiobook files or folders are removed from your device: a book whose files are all gone is hidden (kept, with its progress, in case it comes back) and a book that lost only some files is trimmed
- On launch, if an update is available you'll get an update screen with the release notes and Install / Skip. Skipping suppresses only that version, so the next release still prompts you
- Reset library action in Settings → Library — clears every book from the app (your audio files on disk are kept) for a clean re-scan

### Changed
- Series are now first-class: the library keeps a proper series record (seeded automatically from your existing series info). This is the groundwork for series covers, a series info screen, series-wide options, and continuous series playback arriving in upcoming beta updates
- Automatic book "joining" has been retired in favour of the new series system

## [1.5.2b] - 2026-06-29

- Auto-rewind no longer overshoots past the start of a chapter when the saved position within the file is shorter than the rewind amount

## [1.5.1b] - 2026-06-29

### Fixed

- Opening a book from the home screen no longer triggers multiple simultaneous play() calls when the player screen reloads

## [1.4.0b] - 2026-06-27

### Added
- The home now-playing / resume card now expands upward into the full player with a smooth container-transform animation (and collapses back on return)
- Modern adaptive launcher icon: a compass rose on a deep navy gradient, with a themed-icon (monochrome) layer for Android 13+
- The widget's play button now starts the last-played book from cold — no need to open the app first; it restores position, speed, and per-book volume boost/EQ

### Changed
- Book info and the player are now a single screen with no navigation between them: tapping Resume crossfades in place, and back / swipe-back from either always returns straight to the home screen (never bounces to the info panel)
- Refresh is now strictly additive: existing books are never re-titled, re-grouped, or reset — only brand-new folders are added, and new files dropped into an existing book are appended without touching its progress
- Manually joined or split books are now permanently respected; a refresh will never silently re-join a group you split or disturb one you created
- Books are no longer artificially divided into chapters; a file shows chapters only when its own metadata defines them (existing auto-sliced chapters are cleaned up on launch)
- Continued the app-wide reskin onto the player's design language: squircle cards, accent-tinted controls, pill buttons, and list animations across Search, Series, and the Join-books editor
